# Growmie

Marketing site for [Growmie](https://growmieapp.com/) — Learn. Teach. Earn.

Live classes, a 70% creator share, and payouts within 24 hours. Available on [Android](https://play.google.com/store/apps/details?id=com.growmie.app) and [iPhone](https://apps.apple.com/us/app/growmie/id6746710801).

## Local

```bash
npm install
npm run dev
```
